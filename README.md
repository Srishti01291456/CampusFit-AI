# CampusFit AI — Inclusive Fitness & Wellness

An easy-to-moderate, full-stack AI/ML educational project. It uses Flask (not Streamlit), HTML/CSS/JavaScript, SQLite, pandas and scikit-learn. The UI includes separate general-fitness and inclusive-support flows, two ML predictions, trackers, charts, favorites, a wellness chat helper, meal ideas, a basic food-image demo and a personal story log.

> **Important dataset note:** Both included CSVs are reproducible **synthetic demonstration datasets**, generated by `generate_datasets.py`. They are not real participant records, clinical data, or validated exercise prescriptions. The inclusive labels are curated demo categories. This is appropriate for demonstrating preprocessing and model training, but do not describe the data as collected from disabled people or use the predictions for healthcare decisions.

## Run locally (Windows PowerShell)

```powershell
cd campusfit-ai
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python generate_datasets.py
python train_models.py
python app.py
```

Open http://127.0.0.1:5000. Health check: http://127.0.0.1:5000/health. The first two commands regenerate the demo CSVs and train/save both models under `models/`.

## AI/ML pipeline

- `general_fitness.csv` → Random Forest classifier → `models/general_fitness.joblib`
- `inclusive_activity.csv` → Decision Tree classifier → `models/inclusive_activity.joblib`
- Each pipeline uses a train/test split **before** fitting imputers, encoders, scalers and feature selection. Numeric missing values use median imputation and standard scaling; categorical missing values use most-frequent imputation and one-hot encoding. `SelectKBest(k=10)` retains up to ten transformed features; the notebook reports before/after counts. Classification accuracy and reports are written to `models/metrics.json`.
- The food image endpoint is deliberately a transparent colour-feature demo, **not** a trained food recognition model. Replace it with a properly trained image classifier and a licensed dataset before claiming food recognition.
- The coach is a simple response helper, not a generative AI model.

## Deploy

### Render (Docker)
1. Push this repository to GitHub.
2. In Render, create **New → Web Service**, connect the repository, choose **Docker**.
3. Set health check path to `/health`.
4. Deploy. Render provides a public URL.

The included Dockerfile trains models during image build so the API has model artifacts. SQLite on free/ephemeral hosting may reset on redeploy; use a managed persistent database/volume if you need durable user data. Set a strong `SECRET_KEY` environment variable. Do not collect sensitive health information.

## Dataset and academic integrity

The two CSVs are generated locally with a fixed random seed. Cite this project and clearly identify them as synthetic. If your instructor requires external real-world datasets, select a properly licensed, relevant dataset and document its source, permitted use, population limitations and label meaning. Do not treat a general fitness dataset as representative of people with disabilities. Keep the inclusive demo dataset separate unless a suitable, ethically sourced dataset is available.

## Limitations and safety

This is a student prototype. It does not diagnose disability, assess clinical fitness, prescribe rehabilitation, calculate validated nutrition, detect allergens or provide emergency support. The user chooses preferences; the model only maps synthetic demo inputs to broad activity labels. Stop activity if uncomfortable and seek qualified guidance for individual safety questions.


## Expanded interactive features

- Exercise cards change for General Fitness, Cognitive Support, and Physical Accessibility. Each card has expandable step-by-step instructions and a YouTube video-search link for demonstrations.
- Nutrition includes vegetarian and non-vegetarian meal ideas across breakfast, lunch, snacks, and dinner.
- AI Coach uses intent-based responses for meals, hydration, exercise, cognitive support, physical accessibility, mood, music, progress, and support contacts. It is a rule-based educational assistant, not a generative medical chatbot.
- Insights chart daily movement, water and mood entries stored in SQLite. Charts show user-entered records only.
- Mood Music offers curated mood categories and opens playlist searches on YouTube.
- Support page includes two counselling contact fields (male and female), a personal consultant and dietitian contact, plus an India helpline directory. All saved phone contacts are stored in the project's SQLite database (`campusfit.db`), not browser local storage. Activity, hydration, mood, favourites and story entries are also stored in SQLite.

### Important feature limitations

Exercise video buttons open YouTube search results rather than embedding a particular creator's video. Playlist buttons likewise open search results; playback is handled by YouTube. The food image scanner in this educational version uses simple image-colour analysis and is not a trained food recognition or nutrition model. Do not use it to estimate calories, ingredients, allergens, or medical dietary suitability.

The cognitive-support and physical-accessibility categories are user-selected preferences, not diagnoses or disability classifications. Exercise suggestions are generic examples; users should only do movements appropriate to their individual circumstances and consult a qualified professional when needed.

Support contacts shown for India: Emergency 112; Tele-MANAS 14416; Department of Empowerment of Persons with Disabilities helpline 9415578606; Nayi Disha intellectual disability helpline 8448448996. Verify current availability before relying on a contact.

## Counsellor contacts and helplines

Open **Support** from the left sidebar. Enter the verified phone number supplied by your college/clinic for the male and female counsellors, then choose **Save number**. The app writes these values to the `support_contacts` table in `campusfit.db`; the saved numbers are loaded back when the app is opened again. The dietitian and personal consultant contacts use the same database table. The two counsellor fields intentionally start blank: do not publish invented or unverified phone numbers.

The helpline directory is preloaded with India-wide contacts including Emergency 112, Tele-MANAS 14416, Women 181, Child 1098, Cybercrime 1930, Disability Information 14456, Nayi Disha 8448448996, KIRAN 1800-599-0019, Anti-Ragging 1800-180-5522, Legal Aid 15100 and Elderline 14567. Contact details can change; the Support page links to official government directories. Call 112 for immediate danger.

**Privacy note:** This is a local educational prototype. SQLite stores records on the machine/server running Flask. Anyone with access to that machine or database file may be able to read saved contact numbers and entries. Do not expose this demo publicly with personal data unless you add authentication, access controls, HTTPS and a suitable privacy notice. The current contact-save endpoint is intended for local demonstration and is not an authenticated admin interface.
